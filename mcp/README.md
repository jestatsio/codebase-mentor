# Codebase Mentor MCP Server

Stdio MCP server exposing the [codebase-mentor](https://github.com/erichare/codebase-mentor) protocol to any MCP-capable agent client. It supplies instructions and artifacts only — there are no LLM calls, no API keys, and zero intelligence in the server; the client's model does the reasoning.

Configure your MCP client to run:

```bash
npx -y codebase-mentor-mcp
```

Example client configuration:

```json
{
  "mcpServers": {
    "codebase-mentor": {
      "command": "npx",
      "args": ["-y", "codebase-mentor-mcp"]
    }
  }
}
```

## Tools

- `codebase_mentor_get_protocol` — the mentor protocol text (`compact: true` for the ~2 KB variant).
- `codebase_mentor_get_onboarding` — locates the project's `ONBOARDING.md` by walking up from `root` (default: the server's working directory), stopping after the directory containing `.git`.
- `codebase_mentor_get_template` — the bundled ONBOARDING.md template and authoring guide.

## Prompts

`mentor` (question), `change_guide` (task), `reconcile` (claim), `scan`, and `onboard` — packaged instructions the client model executes under the accuracy contract: every claim backed by a symbol or file read this session.

## Resources

- `codebase-mentor://protocol` — the full protocol text.
- `codebase-mentor://onboarding` — the current project's ONBOARDING.md, discovered as above.

## Development

The markdown files in `bundled/` are byte-identical copies of the canonical sources (`core/`, `template/`), generated by `scripts/sync-adapters.sh` in the repo root — never edit them by hand.

```bash
npm install
npm run build   # tsc + copy bundled/ into build/
npm test        # build + stdio smoke test
```

See the [main repository](https://github.com/erichare/codebase-mentor) for the protocol, install paths for ~70 agents, and the evaluation.
